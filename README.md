# Takbo! Pinoy Escape Game

A responsive browser-based escape game inspired by 1980s Filipino komiks, jeepney art, bahay-kubo aesthetics, and classic family humor.

Built with vanilla HTML, CSS, and JavaScript.

## Live Demo

GitHub Pages link coming soon.

## About the Game

Find the key, collect optional bonuses, avoid your family, and reach the exit before getting caught.

Each level introduces more pressure:

- Level 1 — Nanay
- Level 2 — Nanay + Tatay
- Level 3 — Nanay + Tatay + Ate

The final level turns into a full family chase.

## Gameplay

1. Find the key.
2. Collect optional food and baon.
3. Avoid the family members chasing you.
4. Reach the exit.
5. Survive all three levels.

## Level Progression

### Level 1 — Nanay

Learn the basic movement and escape mechanics while avoiding Nanay.

### Level 2 — Nanay + Tatay

A second chaser is introduced, making positioning and movement more important.

### Level 3 — Buong Pamilya

Nanay, Tatay, and Ate all chase the player at the same time.

> "Hala ka! Si Ate isusumbong ka na rin!"
